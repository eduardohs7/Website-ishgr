# Escopo de trabalho

O responsável pelo projeto definiu que o trabalho do Codex é exclusivamente no
backend. O front é mantido por outro desenvolvedor.

- Não criar ou alterar HTML, CSS, JavaScript ou o visual das telas, inclusive em
  `backend/templates/` e `backend/static/`, sem nova autorização explícita.
- É permitido ler o front para definir contratos e verificar compatibilidade.
- Implementar rotas, validações, serviços, modelos, permissões e testes no
  backend; entregar instruções de integração em `docs/`.
- Não substituir arquivos do front ao atualizar a cópia de trabalho. Consultar
  as revisões do GitHub sem sobrescrever as implementações locais.
- Usar o checkout existente. Não criar worktrees sem solicitação do usuário.
- Não registrar senhas, cookies ou tokens em arquivos de entrega ou logs.

O contrato atual da autenticação está em `docs/integracao-autenticacao.md`.
O contrato da área do participante está em `docs/integracao-participante.md`.
Para desenvolvimento no Windows, consulte `docs/desenvolvimento-windows.md`;
para a nuvem Linux, consulte `backend/README.md`.
